# proto-harmonic-lexicon

Prototype Streamlit app and dataset for the *Proto-Shared Harmonic Lexicon* project — an exploratory atlas linking Mediterranean and Tamil/Indus motif harmonics.

## Contents
- `data/motifs.csv` — initial placeholder dataset (20 motifs) with metadata, harmonic ratios, and comparative matches.
- `src/app.py` — Streamlit app prototype to explore motifs, preview on a map, and display a correlation network.
- `requirements.txt` — Python dependencies.

## Quickstart (Streamlit Cloud or local)

1. Clone repository:
```bash
git clone <your-repo-url>
cd proto-harmonic-lexicon
```

2. Install dependencies (recommended: virtualenv/venv):
```bash
pip install -r requirements.txt
```

3. Run Streamlit locally:
```bash
streamlit run src/app.py
```

## Data schema
CSV columns include: `id`, `culture_region`, `site_name`, `latitude`, `longitude`, `artifact_type`, `chronology_bce`, `symbol_name`, `image_path`, `symmetry_order`, `node_density`, `fractal_dimension`, `harmonic_ratio`, `semantic_concept`, `comparative_match`, `cross_entropy_score`, `resonance_frequency_hz`, `references`, `notes`.

See `data/motifs.csv` for examples.

## How to contribute
- Add new motif rows to `data/motifs.csv` following the schema.
- Add images to `data/images/` and point `image_path` accordingly.
- Improve visualization, add archaeoacoustic simulation outputs, and link to external metadata.
